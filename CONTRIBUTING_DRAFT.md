# Contribution model (draft, not yet open for public contributions)

The project is pre-launch. **No software/content license, maintainer structure, or public moderation capacity has been selected.** Before encouraging outside contributions, decide those questions transparently and publish a code of conduct, conflict-of-interest guidance, and privacy terms.

## Proposed contribution principles

- Propose concrete, small, testable changes with an accessible alternative.
- Separate observed evidence from personal interpretation and projected impact.
- Do not include private personal data, targeted political profiling, accusations against private people, covert tactics, harassment, or unsupported institutional badges.
- Changes to high-stakes quests require qualified, accountable reviewer approval.
- All contributions must support respectful disagreement and allow correction.

## Initial code workflow (once repository exists)

1. Open an issue with a problem statement and expected benefit.
2. Submit a narrow pull request with tests or documentation.
3. For quest proposals, explain consent, safe stopping conditions, access alternatives, evidence tier, and who was consulted.
4. Maintainers check schema, accessibility, safety, and compatibility before release.
5. Keep an audit trail of corrections and withdrawn quests.

This is a **proposal** for future governance, not an active promise of review or response time.
