# Security and privacy status

This repository contains an **offline, static concept prototype**, not a production online service. The demo does not use accounts, a backend, or analytics. It stores self-reported completion identifiers in the browser's localStorage only. Clearing site data removes this progress.

No production deployment or staffed vulnerability-reporting channel exists yet. Do **not** publish credentials, personal data, or exploitation details in GitHub issues. Before a public deployment, maintainers must establish a private disclosure channel, response process, dependency and security scans, and incident escalation.

For safety concerns in the **design**, propose non-identifying corrections through ordinary discussion once moderation is active. A report route must not promise capacity that does not exist.
